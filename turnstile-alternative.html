The Turnstile errors you're seeing

Most WordPress Turnstile problems trace back to the same handful of errors:

  • 110200 (invalid domain / sitekey mismatch): the widget is loaded for a domain or key Cloudflare doesn't recognise.
  • 106010 (invalid or expired token): the challenge token didn't arrive in time or was used twice, often because of caching or a slow theme.
  • Missing token: a form submits without a Turnstile response, so server-side validation fails.

They're all symptoms of the same thing: a widget that has to load, run and hand a token back before a form can be sent. Cache plugins, JavaScript optimisers, cookie banners and slow connections all get in the way.

oopspam removes the widget entirely. Submissions are scored on your server after they arrive, so there's no token, no challenge and no front-end script to fail. We explain the fixes in our guide to common Turnstile errors.

How to switch from Turnstile

On WordPress it takes a few minutes, and you don't need to edit your forms.

  1. Create a free oopspam account and copy your API key from the dashboard. The free plan includes 40 checks a month, with no credit card.
  2. Install the oopspam Anti-Spam plugin from WordPress.org and activate it.
  3. Paste your key into the My API Key field, or follow the Setup Wizard.
  4. Turn on Activate Spam Protection for each form plugin you use. Comments are protected automatically.
  5. Remove the Turnstile widget and its keys from your forms once you're happy with the results. You can run both while you test.

Not on WordPress? Send each submission to the oopspam API (one call per check), or connect your forms through Zapier or Make.

Turnstile alternative: common questions

Is Cloudflare Turnstile free?

Yes. The free plan includes unlimited challenges, up to 20 widgets and 10 hostnames per widget. Enterprise adds more widgets and hostnames and removes Cloudflare branding, priced through Cloudflare sales (Turnstile plans, checked 5 October 2026).

What does Turnstile error 110200 mean?

It means the domain isn't on the widget's list of allowed hostnames, often after a domain change or on a staging site. Our Turnstile errors guide covers 110200, 106010 and the rest. oopspam has no widget or sitekey, so these errors don't apply.

Does Turnstile check what people write?

No. Turnstile checks whether a visitor looks like a bot; it doesn't read the message. That's why spam written by real people still gets through. oopspam scores the content, email, IP, country and language of each submission.

Do I need a Cloudflare account to use oopspam?

No. oopspam works on any host, with or without Cloudflare.

Does oopspam store my visitors' data?

Not by default. The oopspam API scores each submission without storing it, so there is no data to identify or track your visitors. See our GDPR notice and Data Processing Agreement.

How much does oopspam cost?

You can start with 40 free spam checks a month, no credit card required. Paid plans start at $23/month for 25,000 checks, and every plan covers unlimited websites. See pricing.
