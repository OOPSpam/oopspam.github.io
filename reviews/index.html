Questions people ask before choosing oopspam

Are these reviews real?

Yes. Every review on this page was published by a customer on WordPress.org or Trustpilot, and each one links to the original so you can check it. We show a selection, including a critical one, and mark any words left out with an ellipsis (…).

Does oopspam work with WooCommerce?

Yes. The WordPress plugin protects WooCommerce orders and checkout on your server. Store owners use it against spam orders and card testing, for example this review about 800 fake orders a day. More on the WooCommerce page.

Do I still need a CAPTCHA?

No. oopspam checks submissions on your server, so visitors never see a puzzle. One reviewer found that “CAPTCHA wasn't doing much to slow it down” before switching (read the review).

What happens if a real message is marked as spam?

Every submission gets a spam score, and you choose how strict the filter is with the sensitivity setting. In WordPress, blocked entries are kept in the plugin's logs, where you can review them and report a misdetection so the filter learns from it.

Is oopspam GDPR compliant?

Yes. The oopspam API doesn't store submission data by default, so there is no data to identify or track your visitors. See the GDPR notice and the Data Processing Agreement.

How much does oopspam cost?

You can start with 40 free spam checks a month, no credit card required. Paid plans start at $23/month for 25,000 checks, and every plan covers unlimited websites. See pricing.
