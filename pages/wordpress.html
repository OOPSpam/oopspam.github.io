Frequently Asked Questions (FAQ)

How many API calls do I need? 🤔

1 API call = 1 spam check

When someone submits a form on your website, that counts as one API call. For example:

  • The Freelance plan (100,000 API calls) typically covers ~100 websites
  • Average website gets 20-50 form submissions daily
  • WordPress users: count your monthly form submissions across all sites
Does the oopspam WordPress plugin support the Form Builder plugin I use?

It supports most of the popular contact form builders. See the full list.

How do I configure the oopspam WordPress plugin?

Check out the Configuration page on the knowledge base. If something isn't working as expected, see Troubleshooting.

Is the oopspam WordPress plugin free?

The plugin is free to install from WordPress.org. It needs an oopspam API key, and every account includes 40 free spam checks a month. Paid plans are priced by number of checks, not by number of sites.

Will it slow down my website?

No. Checks run on your server when a form is submitted, so nothing extra loads in your visitors' browsers and there is no CAPTCHA script on your pages.

Does it protect WooCommerce, logins and registrations?

Yes. Besides contact forms and comments, it protects WordPress login, registration and lost-password forms, WooCommerce orders and registrations, and membership plugins. In WooCommerce it also helps stop card testing on checkout.

Is it GDPR compliant? Where are submissions stored?

Logs are kept in your own WordPress database, and nothing is stored on oopspam's servers unless you turn on remote logging. You can stop IP and email checks and strip sensitive details from messages in the Privacy settings. See our GDPR notice and Data Processing Agreement.

What if a real message is blocked?

Find it in the plugin's spam entries log, which shows why it was blocked. Add the sender's email or IP to your allowed lists, or lower the sensitivity level.

Can I keep reCAPTCHA or a honeypot?

Yes. oopspam works alongside them. If you remove reCAPTCHA, your pages no longer load Google's script.
